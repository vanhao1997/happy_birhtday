# Pixel Asset Sources

The birthday map uses files supplied by the project owner:

- `Farm RPG FREE 16x16 - Tiny Asset Pack` for terrain, house, trees, crops, animals and the top-down player sprite.
- `Tiny RPG Character Asset Pack 01 v2.0 -Free Soldier&Orc` for the non-playable soldier and orc idle sprites.

The supplied archives did not include a README, license or credit file. Keep these assets in the internal birthday project until commercial or public distribution rights are verified with the original author. The generated `grass-fill.png` and `dirt-fill.png` files are small crops of the supplied tiles, with opaque black mask pixels removed so the tiles can repeat cleanly.
